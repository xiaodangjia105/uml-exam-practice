# UML 期末练习工具

一个干净简洁的 UML 期末考试在线练习工具，单 HTML 文件即可运行，无需任何依赖。

## ✨ 功能

- **选择题 & 判断题**：收录 19 道选择题 + 13 道判断题，共 32 题
- **即时练习**：选中选项后自动记录，顶部进度条实时显示答题进度
- **智能批改**：提交后自动评分，错题和未答题高亮显示正确答案
- **重新练习**：一键重置，可反复练习
- **移动端适配**：响应式设计，手机也能用

## 🚀 使用方式

### 方式一：直接打开（推荐）

1. 下载 `index.html`
2. 双击在浏览器中打开
3. 开始练习！

### 方式二：本地服务器

```bash
# 使用 Python
python -m http.server 8080
# 浏览器打开 http://localhost:8080

# 使用 Node.js
npx serve .
```

## 📋 题目来源

题目来自 UML 期末考试复习资料，涵盖：
- UML 基本概念与核心关系
- 类图、对象图、用例图
- 状态图、活动图、顺序图
- 组件图、部署图、包图
- 面向对象基本特征
- UML 建模工具与原则

纯原生 HTML + CSS + JavaScript，无框架，无依赖。
